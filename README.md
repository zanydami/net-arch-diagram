# Mobile Network Architecture

Интерактивный справочник по архитектурам мобильных сетей. Проект визуализирует 2G, 3G, 4G, 5G NSA и 5G SA и помогает изучать узлы сети, связи между ними и интерфейсы.

## Возможности


Поддерживаются клавиатурное управление узлами и закрытие справочника клавишей `Escape`.

## Запуск


```bash
npm install
npm run dev
```

Откройте [http://localhost:4173/](http://localhost:4173/). Для запуска без режима разработки используйте `npm start`.

### Сборка и просмотр production-версии

```bash
npm run build
npm run preview
```

Preview будет доступен на `http://localhost:4173/`.

## Тесты

Запустите `npm test`, чтобы проверить целостность схем и обработку состояния приложения. Для встроенной поддержки TypeScript в тестах требуется Node.js 22.6 или новее.

## Хранилище справочника

Для совместного редактирования используется Supabase. Статические данные остаются резервными значениями, а `reference_entries` хранит только пользовательские переопределения полей описания, расшифровки и подробностей.

1. Создайте Supabase-проект и выполните SQL из `supabase/migrations/202611070001_reference_editing.sql` в SQL Editor.
2. Скопируйте `.env.example` в `.env.local` и задайте `VITE_SUPABASE_URL` и публичный `VITE_SUPABASE_ANON_KEY` из настроек проекта. Не добавляйте `service_role` key во frontend или репозиторий.
3. В **Authentication → URL Configuration** добавьте URL локальной разработки (`http://localhost:4173`) и production-сайта в Redirect URLs. При запуске на другом порту добавьте соответствующий origin.
4. Включите Email provider и зарегистрируйте пользователя через кнопку входа в приложении. Новые аккаунты получают роль `reader` и не могут менять общие данные.
5. Назначьте редактора или администратора из SQL Editor, подставив email аккаунта:

```sql
update public.profiles
set role = 'editor'
where id = (select id from auth.users where email = 'editor@example.com');
```

Роли ограничиваются Row Level Security. Журнал изменений доступен администраторам; пользователи без роли редактора могут только читать справочник.

## Порт

Dev-сервер и preview используют порт `4173` и настроены с `strictPort`: если порт занят, Vite завершит запуск с ошибкой, а не выберет другой порт автоматически. Остановите процесс, который уже использует порт, или освободите его, затем повторите команду.

## Структура проекта

```text
src/
├── components/
│   ├── ArchitectureDiagram.tsx   # Схема, узлы, связи и их интерактивность
│   ├── DetailPanel.tsx           # Краткая карточка выбранного узла
│   ├── ReferenceDirectory.tsx    # Поиск и подробный справочник
│   └── TechnologyTabs.tsx        # Переключение поколения сети
├── data/
│   ├── technologies.ts           # Узлы, слои и связи схем
│   ├── interfaceDescriptions.ts  # Краткие описания интерфейсов
│   ├── referenceDetails.ts       # Расшифровки и подробные описания
│   └── specificationSources.ts  # Ссылки на спецификации 3GPP
├── App.tsx                       # Состояние приложения, тема и URL
└── index.css                     # Глобальные стили и палитры тем
```

## URL-параметры

- `tech` — идентификатор поколения: `2g`, `3g`, `4g`, `5g-nsa` или `5g-sa`.
- `node` — идентификатор выбранного узла в активной схеме.

Например: `http://localhost:4173/?tech=4g`.
